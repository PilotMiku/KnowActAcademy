# 题库转写与两版合并

本轮读取 137 份原始 PDF（3,716 题）和两个补充文件夹中的 182 份 HTML（实际 5,346 题）。统一题库共 8,425 题，其中高数 6,985 题、线代 1,440 题，包含高数十章和线代七章。637 条补充来源合并到已有题目，原题 ID、所属小节、选项顺序和答案字母均保留，已有学习记录可以继续使用。

## 转写状态

正式网页采用文字、已校验 LaTeX 和原始图像共同呈现。39,433 次公式出现已转为 LaTeX；40,494 次尚未可靠确认的表达式保留原式，另有 234 个 PDF 内容块和 2,058 个补充内容块整体保留为图像。图像按内容去重后共 41,138 张，存入 256 个带内容摘要的 JSON 文件，按需读取。未经检查的 OCR 候选不会替换正式题库。

全量文字加 LaTeX 候选保存在 `artifacts/pdf-transcription/unified-native-draft.json`，逐部分的识别、来源和检查状态保存在 `unified-review.json`。2,770 题的全部转写部分通过了当前来源检查，其余仍有待复核项。“来源检查”表示字形、数学排版结构或独立识别相符，不表示所有题目已经逐题人工重新求解。未确认的近似重复题保留为独立题目，不仅凭中文相似度合并。

补充资料中有 293 处图片实际是 404 错误页，其中也包含题干和选项；部分解析可由原版补足。最终仍有 60 题缺少可用主解析，19 题的原始题干或选项有缺损，均明确标注。文件标题声明的题量与实际题量有 16 处不一致，登记表记录两者；不会按标题补造题目。

## 答案和解析更正

- 积分性质题 `s-28375703e59c-q0045`：两版答案冲突，核对选项及不等式方向后保留原版 A。
- 奇延拓题 `s-96a0c9ad9285-q0005`：核对得到 `(x−2π)cos x`，补充版多了负号；保留原版 C，并避免把选项对应不同的解析直接附到题后。
- 拉格朗日中值定理题 `s-6d7a175c5f89-q0034`：由 `m=1/[3(ξ−1)^(2/3)]` 得到 `ξ=1+1/√(27m³)`；修正题干条件、A 选项及解析中的漏项。
- 悬链线旋转体题 `s-7f0c2b8999dd-q0030`：换元 `x/a` 后的积分上限改为 1。
- 等温气体题 `s-84aefb2c6fa0-q0021`：压强与体积的关系改为反比，与 `P=k/V` 一致。

来源别名、冲突处理理由和更正内容在 `data/questionbank-unification.json`。原始 PDF 和 HTML 已从当前分支移除，完整原件保留在固定的历史提交；归档登记包含 SHA-256。

## 部署与文档

旧网站约 278.5 MiB、22,574 个文件；新网站约 87.4 MiB、404 个文件，题量增加后仍减少约 68.6% 体积。原始数学 PDF 不再重复打包到 Pages，通过题目来源链接查看固定历史提交中的原件。知识资料继续随网站发布。此项减少部署负担，不能保证 GitHub Pages 服务端不会再排队或超时。

`artifacts/知行学习-统一题库文档.zip` 包含 17 份分章 Word、17 份全量文字 LaTeX 校对稿、逐题 CSV 和统计说明。Word 共有 39,727 个原生公式，未确认表达式保留图片；文本校对稿按部分标出状态，尚不能作为全部完成的定稿。导出脚本检查每道题的 ID 是否出现在 Word 文档 XML 中。Word 导出仅规范化等价命令及不显示的排版标记，不改网页 LaTeX。

完整备份导出使用紧凑 JSON，避免因缩进使新题库的备份超过自身 50 MiB 恢复限制。公式图片在网站共享资源中，不重复塞入学习备份。

验证通过：69 项 JavaScript 测试、32 项 Python 测试、全部静态资源检查，以及分批运行的 18 组浏览器回归。检查包含全部已发布 LaTeX 的渲染、全部原题 ID 和答案字母保留、根路径与仓库子路径、17 个大章抽样、手机排版、完整备份恢复、真实后端双设备同步和题图缩放。转换及文档已提交 GitHub，自动部署状态以 Actions 为准。

## 重建与继续校对

普通网站构建仅需项目原有依赖：

```sh
python scripts/check_bank.py
npm test
python -m unittest discover -s tests -p 'test_*.py'
python scripts/build_static.py
python scripts/verify_site.py
npm run test:browser
```

重跑识别需要本地模型和识别缓存；它们未加入 Git，也不参与 Pages 构建。脚本在 `experiments/pdf-documents/`，识别、分割和字形校验均在本机执行。全部文字候选与正式网站数据分离。修正来源记录或补充人工核对后，依次执行 `assemble.py`、`compare_versions.py`、`unify.py`、`validate_transcription.mjs` 和 `prepare_native_site.py --publish`，再构建验证网站。`--publish` 仅更新本地 `dist` 数据。

完整文档由 `export_unified.py` 生成，需要 Pillow 和 Pandoc。旧 PDF 题库快照保存在 `data/pdf-source-bank.json`；旧版截图索引脚本会拒绝直接覆盖当前统一题库。

## 2026-11-12：继续转换并导出逐题 Markdown

重新识别了 496 条旧的截断记录，其中 360 条补全；另从原始字形坐标恢复行列式网格，并独立比对通过 142 条公式，人工核对补写 37 条长公式。原版 PDF 的截断公式从 249 条降至 4 条。修复标准根式等旧命令的兼容语法，不推测缺失的根指数、符号或矩阵元素。

`question-bank-markdown/` 包含全部 8,425 题的 17 份分章 Markdown 及单题压缩包。每题附答案、解析、来源、ID 和校对状态；使用 `$...$` / `$$...$$` 表示数学公式，不引用截图。7,613 题有完整、非截断且可渲染的文字候选，2,770 题通过当前全部来源检查；二者均不等于全部人工重新求解。其余题目的缺损或不能渲染的候选以明确标记和 LaTeX 代码保留，不补造内容。

导出报告在 `data/markdown-transcription-report.json`，单题 CSV、文件摘要清单和 8,425 份独立 Markdown 均包含在 `question-bank-markdown/逐题Markdown.zip`。这些文档不进入 Pages 发布包。

## 原始资源清理

从当前分支移除 137 份数学 PDF 与 182 份图片型补充 HTML，共 289,728,366 字节（约 276 MiB）。没有重写 Git 历史：每份原件仍可在 `276c33298d98f896b31daf7d73607977bffd666a` 中查看，归档清单在 `data/archived-math-sources.json`。删除前逐文件比较工作区、本地缓存与该提交的 SHA-256；来源链接改为固定提交，继续支持未核实内容的校对。

网站需要的 256 个共享图像文件和 37 份学习资料仍保留。原始题库快照、来源摘要及裁切索引用于题目身份、答案和来源验证。普通构建依据明确的归档登记验证已移除数学资料，不依赖 OCR 缓存；未登记的新文件、摘要不匹配及缺少学习资料仍会导致检查失败。

OCR 脚本可读取经过摘要检查的 `.cache/source-archives/` 原件；新克隆可先执行 README 中的历史提交获取和本地恢复命令。Markdown 和网站的全部来源链接均固定到原件所在提交，8,425 题的题干、选项、答案、解析与 ID 保持不变。

本轮清理在不含原始数学文件和 OCR 缓存的干净目录中通过 70 项 JavaScript 测试、34 项 Python 测试、入库检查、构建及静态校验。浏览器验证覆盖全部大章抽样、历史来源、真实双设备同步和学习资料。Finder 目录缓存取消 Git 跟踪但保留本地文件，构建也会排除目录缓存。
