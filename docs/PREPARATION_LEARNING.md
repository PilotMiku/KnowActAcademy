# 备考中的掌握与间隔抽测

答对即掌握，从普通训练队列移出。下一组优先未做题和待巩固错题，后续组继续穿插少量已做题抽测。

## 掌握规则

- 首次答对即掌握，包括标记“拿不准”的正确作答。“拿不准”提高后续抽测优先级。
- 答对后的反馈中提供“其实不会做”。选择后撤销掌握，将本次作答改记为错误，加入错题本；掌握率、本组正确率、预测、复习安排和错题权重同步更新。重复点击不会增加错误次数，也不会增加作答次数。
- 解答题查看参考答案不计掌握，自评“本次答对”后即掌握，也可以选择“其实不会做”改记错题。
- 答错或选择“其实不会做”回到待巩固。之后答对一次即可重新掌握，错题本同步标为已掌握；再次答错会重新打开错题。
- 同一场次同题只计算一次。普通练习和其他备考计划的作答不改变本计划掌握统计。

## 抽题安排

测评记为第 0 组。第 n 组答对的题，最早在第 n+2 组抽测；如果已满 24 小时，也可以再次抽测。完成一次间隔抽测后，等待原有间隔复习计划到期再参与后续抽测。

每组上限仍采用当前题量设置。抽测名额为上限的约 15%，向上取整，最多 3 道；例如 20 题组最多 3 道、短组通常 1 道。未做题和待巩固题不足时缩短本组，不用刚答对的题凑满。

抽测综合当前星级、历史错题、不确定标记及距上次作答时间。星级使用个人标注优先的现有难度体系；尚未标注的题采用中性权重。有多个抽测名额时，保留一个从全部合格候选随机抽取的名额，其他名额优先高风险候选。

新题至少预留约四分之一名额，错题保留加强机会。其余普通训练按小节已选题量降低重复权重，再打乱顺序。没有待练或合格抽测题时，页面提示先学习其他范围或次日再来，不建立空组、不推进场次。

## 看板与预测

掌握率按本计划每题最近一次有效作答统计，答对即计入；答错或选择“其实不会做”移出掌握量。看板显示已掌握题量、掌握率、覆盖量和待巩固错题量。

预测仍要求覆盖不同题目、各所选小节和足够的独立作答。标记不确定的正确作答保留保守的训练表现分，但不阻止掌握。掌握率达到 100% 不会解除预测的样本门槛。

掌握状态从原有作答记录重建，历史答对题直接计为掌握，无需再确认。抽测题号、场次和改记错题后的作答共同备份，恢复后继续遵循间隔与防重复提交规则。

## 研究依据与边界

主动回忆有助于延迟保持；数学练习中的间隔和混合出题也有实验支持。间隔安排需要考虑保持目标、内容和学习者，不能把“隔两场”“15%”或“最多三题”称为普遍最优值。这些是减少无效重复、保留学习反馈的产品默认值，抽查权重是启发式排序，不是经过个人数据拟合的遗忘概率。

- [Roediger & Karpicke（2006）：测试与长期保持](https://pubmed.ncbi.nlm.nih.gov/16507066/)。
- [Rohrer & Taylor（2007）：数学问题的间隔与混合练习](https://eric.ed.gov/?id=EJ786797)。
- [Rawson & Dunlosky（2011）：重复提取和后续间隔重学的效率](https://pubmed.ncbi.nlm.nih.gov/21707204/)。该研究的材料和推荐练习量不等于本产品的“答对即掌握加少量抽测”规则。

如需检验迁移，后续可以另做同知识点、不同数字或不同问法的测验；当前的原题抽查不能证明已掌握所有变式题。每题星级也不等于个人遗忘风险。
