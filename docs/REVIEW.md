# 知行学习迁移复审

日期：2026-10-23。此记录针对本地交付版本；没有上传 GitHub，没有连接用户的生产服务器。

## 结论

GitHub Pages 所需的完整静态网站已经构建。浏览器能在根路径和仓库子路径启动，题目图片与原始资料均不再依赖 Python 动态渲染。保持原有主要刷题流程，服务器同步为主动使用的附加功能。

题库、原始 PDF、Markdown、题目与知识索引保持逐字节一致。`docs/original-checksums.json` 保存迁移前原项目文件的 SHA-256，`scripts/verify_original.py` 可以复核原项目源码和新旧题库的一致性。

## 复审重点与修正

| 检查点 | 结果与处理 |
| --- | --- |
| GitHub Pages 仓库子路径 | 原题 JSON 不改写，渲染阶段将旧题图路径转换为相对静态路径；原 PDF 链接改为相对地址 |
| 原版题目显示 | 继续使用原裁切索引、渲染比例、答案标记遮盖和无损 WebP；没有 OCR 或重写公式 |
| 原项目学习记录 | 新站按仓库路径使用独立 IndexedDB；通过兼容的完整备份迁移旧记录 |
| 题库与知识点完整性 | 每份来源校验 SHA-256；静态输出检查全部图片引用和资料下载文件 |
| 失败构建 | 完成新输出后切换目录；保留、恢复上一次可用输出，避免提前删除网站 |
| 刷新与缓存 | 使用哈希路由；题图保留原版本参数；没有加入可能长期保留旧题库的 Service Worker |
| 可选服务器故障 | 前端默认零后端依赖；同步网络错误不撤销浏览器保存 |
| 跨设备覆盖 | 手动上传/恢复、If-Match 版本比较、SQLite 写事务、10 次历史快照；冲突不自动覆盖 |
| 恢复前本机备份 | 获取和验证服务器进度后，下载本机完整备份，再替换并持久化本机状态 |
| 考试状态 | 本机有进行中的考试时禁止同步；拒绝恢复仍在进行的远端考试；到期远端考试先按原逻辑交卷 |
| 损坏备份 | 无效练习恢复信息重置为无进行中练习；无效考试结构与题目关联拒绝导入；保留旧备份兼容 |
| 特殊题目 ID | 拒绝 `__proto__`、`constructor`、`prototype` 等保留 ID，避免导入记录与对象属性冲突 |
| 确认按钮重复触发 | 在异步确认回调进行时阻止重复执行 |
| 题干 HTML | 沿用元素白名单与纯文本属性处理；脚本、事件属性、iframe 等不会执行；KaTeX 禁用 trust |
| 同步身份 | 每位用户独立 256 位随机密钥，服务器只保存 SHA-256；密钥只保存在页面内存 |
| 跨域与请求 | 明确来源白名单、Bearer 鉴权、HTTPS、禁止重定向、10 MiB 上限和 JSON 格式检查 |
| 发布边界 | 仅发布 `_site/`，后端源码、SQLite、密钥与测试备份不进入静态发布产物 |
| 索引器 | 新项目的目录扫描忽略 `_site/`，不把发布副本识别为新增题库 |

- `docker compose config --quiet`：配置解析通过；未在本机启动 Docker 容器或在真实服务器上运行生产镜像。
- 人工查看桌面首页、手机答题页和手机同步管理页截图，确认导航、题图、答案和按钮正常；长公式和原题解析继续使用原有横向滚动方式。

浏览器报告与截图保存在 `artifacts/`（不提交仓库）；`_site/build-manifest.json` 记录题库版本、题量、资源数量及原始 JSON 摘要。

## 使用边界

本次只交付本地源码和构建结果，没有执行线上部署。实际服务器域名、TLS、允许来源、管理员分配的个人密钥和数据库定期备份需要在自有服务器部署时设置。

服务器当前提供快照上传和恢复，不自动合并并发学习记录；自定义题库沿用完整备份迁移。浏览器侧学习数据仍依赖网站存储空间，清理或换域名前应使用备份或主动同步。静态题库中包含标准答案，这与原项目一致，模拟考试用于自测。
