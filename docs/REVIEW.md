# 知行学习迁移复审

日期：2026-10-23。此记录针对本地交付版本；没有上传 GitHub，没有连接用户的生产服务器。

## 结论

GitHub Pages 所需的完整静态网站已经构建。浏览器能在根路径和仓库子路径启动，题目图片与原始资料均不再依赖 Python 动态渲染。保持原有主要刷题流程，服务器同步为主动使用的附加功能。

题库、原始 PDF、Markdown、题目与知识索引保持逐字节一致。`docs/original-checksums.json` 保存迁移前原项目文件的 SHA-256，`scripts/verify_original.py` 可以复核原项目源码和新旧题库的一致性。

## 使用边界

本次只交付本地源码和构建结果，没有执行线上部署。实际服务器域名、TLS、允许来源、管理员分配的个人密钥和数据库定期备份需要在自有服务器部署时设置。

服务器当前提供快照上传和恢复，不自动合并并发学习记录；自定义题库沿用完整备份迁移。浏览器侧学习数据仍依赖网站存储空间，清理或换域名前应使用备份或主动同步。静态题库中包含标准答案，这与原项目一致，模拟考试用于自测。

## 2026-10-26 随机题量与加权备考复查

随机刷题增加“25 题 / 所有题目”选择，均遵循当前筛选条件。所有题目采用随机排列，题库顺序不变，同组不重复，支持原有 40 题分页导航和刷新恢复。范围不足 25 题时取全部题目。

备考采用“选择一个科目及多个大章或小节 → 均匀随机测评 20 题 → 每组 20 题加权训练”的流程。所选大章包含全部后代小节，重叠范围去重；范围不足 20 题时取全部题目。每组结果展示已完成、答对数量和正确率，复习重点按小节与题型显示。跳过题目不当作答错，但须补完本组才能抽下一组；解答题只有完成自评后才计入完成与权重。

权重由本次计划中的作答记录推导，不改原题及答案，也不向题库 JSON 写入学习权重。小节、同小节同题型、单题分别维护需求值，初值为 1；每次作答更新为 `旧值 × 0.6 + 目标值 × 0.4`，错误目标为 4，正确目标为 0.25。每题最终权重为三类需求值的 50%、30%、20% 加权和；上一组出现的题目再乘以 0.7。按指数竞赛法不放回抽样，所有题目保持正权重，下一组使用最新作答重新计算。新测评建立独立计划，旧作答继续保留于统计和错题记录。
